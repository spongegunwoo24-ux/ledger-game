## M1 — 핵심 루프 (재미 확인용) ✅ — 의뢰인 확인 대기

- [x] 새벽 항구 게시판(물때/달/날씨), 바다 지도(어장 6곳 + 잠긴 "그 자리"), 그물질 장면(숫자 게이지 없음: 윈치 소리 높이, 줄 떨림, 배 기울기, 그물 자루 크기, 거스의 말), 그물 걸림과 수선(부두에서 직접 / $40 즉시)
- [x] 갑판 분류: 소·중·대 바구니, 게 양동이, 쓰레기통, 챙김 상자, 거북은 난간 너머로, 잡어는 장부에게(공중에서 받아먹음), 장부가 8초마다 새우 훔치기, 거스가 절반 정도 같이 고르며 말하기
- [x] 통조림 트럭 판매, 금요일 자동 납부(부족·연장·경고·압류 포함), 주간 정산
- [x] 1주차 이벤트 W1_* 전부(1~7일) 플레이 가능
- [x] 30초 그물질 + 분류 + 판매의 손맛: 첨벙, 퐁당, 계산대 종, 동전 날아가기, 물보라, 화면 흔들림 없음

### 플레이 테스트 방법
- 처음부터: 새 게임 → 1일차 장례식부터.
- 특정 날로: `?debug=1` → 디버그 패널 "날짜"에 일수와 구간 입력 → 이동.
- 이벤트만 보기: 디버그 패널 "이벤트"에서 ID 고르고 실행.
- 경제 시뮬레이션: 디버그 패널 "시뮬"에서 poor/average/great, 일수 → 자동 진행 결과 출력.

### 확인한 것
- 헤드리스 브라우저 자동 플레이로 1일차 아침 → 8일차 새벽까지 오류 없이 진행 (이벤트 12개, Q_BOTTLE 완료, 편지 7통, 7일차 $250 납부).
- 단위 테스트 46개 통과 (달력, 저장, 경제, 분류, 그물질, 퀘스트, 콘텐츠, 스포일러, 정해진 날짜).

### 아직 안 된 것 (다음 단계)
- 2~10주차 이벤트, 나머지 퀘스트, 편지 L13~L72 (M2, M4).
- 상점·장식·안전장치 전부 (M3). 이번 단계에는 압류 결말과 거스의 커피 깡통, 첫 연장만 있음.
- 사건 벽은 공식 진술 카드 보기만 됨 (증거 연결은 M4).
- 마을 사람들 평소 대사는 사람당 3~6줄 (M2에서 15줄 이상으로).

## 알려진 문제
- 헤드리스(소프트웨어 렌더링) 환경에서는 프레임이 낮게 나옴. 실제 브라우저에서 60fps 확인은 의뢰인 플레이 후 M6에서 다시 측정.
