- [x] 통조림 트럭 판매, 금요일 자동 납부, 주간 정산 (상환 규칙은 변경 요청 1에서 새로 바뀜)

### 플레이 테스트 방법
- 처음부터: 새 게임 → 1일차 장례식부터.
- 특정 날로: `?debug=1` → 디버그 패널 "날짜"에 일수와 구간 입력 → 이동.
- 이벤트만 보기: 디버그 패널 "이벤트"에서 ID 고르고 실행.
- 경제 시뮬레이션: 디버그 패널 "시뮬"에서 poor/average/great, 일수 → 자동 진행 결과 출력.

### 확인한 것
- 헤드리스 브라우저 자동 플레이로 1일차 아침 → 8일차 새벽까지 오류 없이 진행 (이벤트 12개, Q_BOTTLE 완료, 편지 7통, 7일차 $250 납부).
- 단위 테스트 46개 통과 (달력, 저장, 경제, 분류, 그물질, 퀘스트, 콘텐츠, 스포일러, 정해진 날짜). (변경 요청 1 이후 61개)

### 아직 안 된 것 (다음 단계)
- 2~10주차 이벤트, 나머지 퀘스트, 편지 L13~L72 (M2, M4).
- 상점·장식 전부 (M3). 낚싯대 업그레이드(긴 줄, 튼튼한 줄, 루어 세트, 어군 탐지기)도 M3 상점에서.
- 사건 벽은 공식 진술 카드 보기만 됨 (증거 연결은 M4).
- 마을 사람들 평소 대사는 사람당 3~6줄 (M2에서 15줄 이상으로).
